H2 : Pourquoi intégrer du PHP dans HTML en 2026 ?

Le PHP et le HTML ne sont pas deux mondes séparés. C'est une illusion pour les débutants. Une page .php est simplement un fichier HTML qui a le super-pouvoir d'exécuter du code côté serveur.

PHP peut être intégré directement dans une page web HTML normale. Cela signifie que tu peux écrire des instructions PHP n'importe où dans ton document HTML. Le serveur PHP va exécuter le code et envoyer le HTML final au navigateur.

WARNING / CHIFFRE CLÉ : 79 % de tous les sites web utilisent PHP côté serveur. PHP est présent sur 7.3 milliards de pages web.

Points les plus importants :

- Créer des pages web dynamiques (contenu qui change).
- Afficher des données personnalisées (Bonjour, [nom]).
- Réutiliser du code (header, footer avec include()).
- Traiter des formulaires (contact, inscription).
- Se connecter à une base de données (MySQL).
- Gérer des sessions utilisateurs (login, panier).

H2 : 1. Les balises PHP : ta porte d'entrée

WARNING / POINT CRITIQUE : Le code PHP DOIT être entre balises pour être exécuté. Sans balises, le code s'affichera tel quel.

H3 : La balise principale : <?php ... ?>

Tout ce que tu places à l'intérieur est interprété par le serveur PHP.
Tout ce qui est à l'extérieur est simplement envoyé au navigateur tel quel.

Exemple de base :

<!DOCTYPE html>
<html>
<head>
    <title>Mon site PHP</title>
</head>
<body>
    <h1>Bonjour le monde</h1>
    <?php echo "Bienvenue sur mon site !"; ?>
</body>
</html>

H3 : La balise raccourcie pour afficher : <?= ... ?>

C'est l'équivalent strict de <?php echo ...; ?>. Utilise-la pour alléger ton code :

<?php
$nom = "Pierre";
?>
<h1>Bonjour <?= $nom ?></h1>

POINTS LES PLUS IMPORTANTS :

- <?php ... ?> est la balise principale pour tout le code PHP.
- <?= ... ?> est un raccourci UNIQUEMENT pour echo.
- Chaque instruction PHP doit se terminer par un point-virgule ;.

H2 : 2. echo et print : afficher du contenu en PHP

WARNING / DANGER : echo et print sont les commandes les plus utilisées. Mauvaise utilisation = code illisible ou erreurs.

La commande la plus basique et essentielle est echo.

Elle prend ce que tu lui donnes et l'imprime à l'endroit exact où tu l'appelles dans ton code HTML.

[IMAGE 3 : ECHO EXEMPLE – 700×400 px]
- Fichier : /assets/articles/generated/php-echo.png
- Alt text : "Exemple d'utilisation de echo et print en PHP pour afficher du contenu dans HTML"
- Position : Centré, avant le tableau comparatif echo vs print
- PSI : < 150 KB

Tableau comparatif echo vs print :

Commande | Usage | Vitesse | Exemple
echo | Affiche une ou plusieurs chaînes | Plus rapide | <h1><?php echo "Bienvenue !"; ?></h1>
print | Alternative à echo | Légèrement plus lente | <p><?php print "Votre score est 100."; ?></p>

Exemples concrets :

<?php
$nom = "Marie";
$age = 25;
?>

<!-- echo simple -->
<p><?php echo "Bonjour, " . $nom; ?></p>

<!-- echo avec plusieurs chaînes -->
<p><?php echo "Tu as "; echo $age; echo " ans."; ?></p>

<!-- Raccourci <?= -->
<p>Bonjour <?= $nom ?>, tu as <?= $age ?> ans.</p>

POINTS LES PLUS IMPORTANTS :

- echo est LE standard pour afficher du contenu.
- echo peut afficher plusieurs chaînes séparées par des virgules.
- <?= $variable ?> est plus court que <?php echo $variable; ?>.

H2 : 3. Mélanger logique PHP et structure HTML

WARNING / CONSEIL PRATIQUE : Le vrai pouvoir se révèle quand tu mèles logique PHP avec HTML. C'est comme ça que tu crées des pages dynamiques.

H3 : Conditions if/else dans HTML

Exemple avec if/else :

<?php
$loggedIn = true;
$nom = "Thomas";
?>

<?php if ($loggedIn) : ?>
    <p>Bonjour, <?= $nom ?> !</p>
<?php else : ?>
    <p>Veuillez vous connecter</p>
<?php endif; ?>

H3 : Boucle foreach pour afficher un tableau

<?php
$villes = ["Paris", "Lyon", "Marseille", "Bordeaux"];
?>

<ul>
    <?php foreach ($villes as $ville) : ?>
        <li><?= $ville ?></li>
    <?php endforeach; ?>
</ul>

Résultat HTML :

<ul>
    <li>Paris</li>
    <li>Lyon</li>
    <li>Marseille</li>
    <li>Bordeaux</li>
</ul>

POINTS LES PLUS IMPORTANTS :

- Utilise la syntaxe alternative (:, endif;, endforeach;) pour mélanger PHP et HTML.
- foreach est parfait pour afficher des tableaux.
- Tu peux ouvrir et fermer les balises PHP plusieurs fois dans le même fichier.

H2 : 4. include() et require() : réutiliser du code PHP

WARNING / ARNAQUE À ÉVITER : Si ton code HTML est long et fouillis,Utilise include() au lieu d'écrire le même code 10 fois.

La fonction include() permet de réutiliser header, footer, navbar sur toutes les pages.

[IMAGE 4 : ARCHITECTURE INCLUDE – 800×500 px]
- Fichier : /assets/articles/generated/php-include-architecture.png
- Alt text : "Architecture de site PHP avec header.php, footer.php et include() pour réutiliser le code"
- Position : Centré, avant l'exemple de structure de fichiers
- PSI : < 150 KB

Exemple de structure avec include :

site.com/
├── includes/
│   ├── header.php
│   ├── footer.php
│   └── navbar.php
├── index.php
├── about.php
└── contact.php

header.php :

<!DOCTYPE html>
<html>
<head>
    <title><?= $title ?? "Mon Site" ?></title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

footer.php :

    <footer>
        <p>&copy; 2026 Mon Site. Tous droits réservés.</p>
    </footer>
</body>
</html>

index.php :

<?php $title = "Accueil"; include 'includes/header.php'; ?>

<main>
    <h1>Bienvenue sur l'accueil</h1>
    <p>Ceci est le contenu principal.</p>
</main>

<?php include 'includes/footer.php'; ?>

include vs require :

Fonction | Comportement si fichier manquant
include | Affiche un warning, continue l'exécution
require | Affiche une erreur, STOP l'exécution

POINTS LES PLUS IMPORTANTS :

- include() permet de réutiliser header, footer, navbar sur toutes les pages.
- Si tu changes le header, tu modifies UN SEUL fichier (header.php).
- require() est pour les fichiers CRITIQUES (configuration, base de données).

H2 : 6. Traitement de formulaires HTML avec PHP

WARNING / DANGER : Ne jamais afficher directement les données du formulaire sans les nettoyer. Utilise htmlspecialchars() pour éviter les injections XSS.

Formulaire HTML simple :

<form method="post" action="contact.php">
    <label for="name">Nom :</label>
    <input type="text" id="name" name="name" required>
    
    <label for="email">Email :</label>
    <input type="email" id="email" name="email" required>
    
    <button type="submit">Envoyer</button>
</form>

Traitement du formulaire avec PHP :

<?php
// contact.php

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $name = trim($_POST['name']);
    $email = filter_var($_POST['email'], FILTER_SANITIZE_EMAIL);
    
    // Validation
    if (empty($name) || empty($email)) {
        $error = "Tous les champs sont requis.";
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $error = "Email invalide.";
    } else {
        echo "<p>Message reçu de " . htmlspecialchars($name) . "</p>";
    }
}
?>

POINTS LES IMPORTANTS :

- $_GET pour les données du formulaire en GET.
- $_POST pour les données du formulaire en POST.
- htmlspecialchars() pour éviter les attaques XSS.
- filter_var() pour valider et nettoyer les données.

H2 : 7. Les erreurs courantes à éviter avec PHP dans HTML

WARNING / ERREUR FRÉQUENTE : 80 % des débutants commettent ces erreurs. Évite-les et tu seras plus rapide.

ERREUR 1 : Utiliser l'extension .html au lieu de .php

Le code PHP s'affiche tel quel dans le navigateur si tu utilises .html.
Utilise toujours .php pour que le code soit exécuté.

ERREUR 2 : Oublier le point-virgule à la fin

<?php
$nom = "Pierre"  // Oubli du ;
?>

Erreur : "Parse error: syntax error"

BON :
<?php
$nom = "Pierre";  // Avec ;
?>

ERREUR 3 : Utiliser une variable non définie

MAUVAIS :
<p>Bonjour <?= $nom ?></p>  // $nom n'existe pas

BON :
<?php $nom = "Pierre"; ?>
<p>Bonjour <?= $nom ?></p>

POINTS LES PLUS IMPORTANTS :

- Toujours utiliser l'extension .php.
- Toujours terminer les instructions par ;.
- Toujours définir les variables AVANT de les utiliser.

H2 : FAQ – Questions Fréquentes sur PHP dans HTML

H3 : Quelle est la différence entre .html et .php ?

Le fichier .html est statique. Le fichier .php est exécuté côté serveur et peut contenir du code PHP dynamique.

H3 : Comment afficher une variable PHP dans HTML ?

Utilise <?= $variable ?> ou <?php echo $variable; ?>.

H3 : include() et require() : quelle différence ?

include() affiche un warning si le fichier manque et continue. require() affiche une erreur et STOP l'exécution.

H3 : Comment sécuriser un formulaire PHP ?

Utilise htmlspecialchars() pour nettoyer les données et filter_var() pour valider les emails.

H3 : PHP fonctionne-t-il dans un fichier .html ?

Non. Le code PHP ne s'exécute que dans les fichiers .php.
