H2 : 1. Les 5 métiers de Data & IA (et lequel choisir)

WARNING / MYTHE À DÉTRUIRE : Tu n'as PAS besoin de devenir Data Scientist pour travailler dans la Data. Data Analyst est un excellent point de départ, mieux payé que beaucoup de développeurs web.

H3 : DATA ANALYST

Rôle : Analyser des données, créer des tableaux de bord, répondre à des questions business.

Outils : SQL, Excel, Power BI/Tableau, Python (basique).

Temps d'apprentissage : 3-6 mois.

Salaire junior : 38 000-48 000 €.

Pour qui : Ceux qui aiment le business, les présentations, les insights.

H3 : DATA SCIENTIST

Rôle : Créer des modèles prédictifs, faire du machine learning, rechercher des patterns complexes.

Outils : Python, SQL, scikit-learn, TensorFlow/PyTorch, statistiques avancées.

Temps d'apprentissage : 12-18 mois.

Salaire junior : 55 000-70 000 €.

Pour qui : Ceux qui aiment les maths, la recherche, les modèles complexes.

H3 : ML ENGINEER (Machine Learning Engineer)

Rôle : Déployer des modèles de ML en production, optimiser la performance, scaler les systèmes.

Outils : Python, SQL, Docker, Kubernetes, AWS/GCP, MLflow.

Temps d'apprentissage : 12-18 mois.

Salaire junior : 60 000-80 000 €.

Pour qui : Ceux qui viennent du développement et veulent faire de l'IA.

H3 : AI ENGINEER

Rôle : Construire des applications avec des LLM (GPT, Claude), créer des chatbots, des agents IA.

Outils : Python, APIs OpenAI/Anthropic, LangChain, RAG, prompt engineering.

Temps d'apprentissage : 6-12 mois.

Salaire junior : 55 000-75 000 €.

Pour qui : Ceux qui veulent travailler sur l'IA générative (le plus tendance en 2026).

H3 : DATA ENGINEER

Rôle : Construire les pipelines de données, nettoyer et préparer les données pour les analystes/scientists.

Outils : SQL, Python, Airflow, Spark, cloud (AWS/GCP/Azure).

Temps d'apprentissage : 9-12 mois.

Salaire junior : 50 000-65 000 €.

Pour qui : Ceux qui aiment l'ingénierie, l'architecture, les systèmes backend.

H2 : 2. Les 5 compétences qui garantissent un emploi (peu importe le métier)

WARNING / POINT CRITIQUE : Tu n'as PAS besoin de tout maîtriser. Ces 5 compétences sont communes à TOUS les métiers Data & IA. Maîtrise-les et tu auras un emploi.

H3 : Compétence 1 : SQL (la base ABSOLUE)

Pourquoi : 100 % des métiers Data utilisent SQL. C'est le langage pour interroger les bases de données.

Ce que tu dois savoir : SELECT, JOIN, GROUP BY, WHERE, sous-requêtes, window functions.

Temps pour maîtriser : 1-2 mois.

Ressources gratuites : SQLBolt, Mode Analytics SQL Tutorial, W3Schools SQL.

Code SQL exemple à maîtriser :

SELECT 
    department, 
    COUNT(*) as employee_count,
    AVG(salary) as avg_salary
FROM employees
WHERE hire_date > '2023-01-01'
GROUP BY department
HAVING AVG(salary) > 50000
ORDER BY avg_salary DESC;

H3 : Compétence 2 : Python pour la Data

Pourquoi : Python est le langage n°1 de la Data et de l'IA.

Bibliothèques essentielles : pandas (manipulation de données), numpy (calcul), matplotlib/seaborn (visualisation).

Temps pour maîtriser : 2-3 mois.

Ressources gratuites : Kaggle Learn, Real Python, pandas documentation.

Code Python pandas exemple à maîtriser :

import pandas as pd

# Charger les données
df = pd.read_csv('data.csv')

# Nettoyer les données
df = df.dropna()
df['date'] = pd.to_datetime(df['date'])

# Analyser les données
summary = df.groupby('category')['value'].agg(['mean', 'sum', 'count'])

# Visualiser
import matplotlib.pyplot as plt
summary['mean'].plot(kind='bar')
plt.show()

H3 : Compétence 3 : Visualisation de données (Power BI ou Tableau)

Pourquoi : Les entreprises veulent des TABLEAUX DE BORD, pas des scripts Python.

Outil à choisir : Power BI (plus répandu en entreprise) ou Tableau (plus puissant).

Temps pour maîtriser : 1-2 mois.

Ressources gratuites : Microsoft Learn (Power BI), Tableau Public (gratuit).

H3 : Compétence 4 : Statistiques de base

Pourquoi : Sans statistiques, tu ne peux pas interpréter les données correctement.

Concepts essentiels : moyenne, médiane, écart-type, distributions, corrélations, tests d'hypothèses.

Temps pour maîtriser : 1-2 mois.

Ressources gratuites : Khan Academy (Statistiques), StatQuest (YouTube).

H3 : Compétence 5 : Compréhension du business

Pourquoi : Les données ne valent rien sans INTERPRÉTATION business.

Ce que tu dois savoir : KPIs, métriques business, ROI, A/B testing, funnel de conversion.

Temps pour maîtriser : 1 mois (en parallèle des projets).

Ressources gratuites : Blogs de growth analytics, cas concrets sur Medium.

POINTS LES PLUS IMPORTANTS :

- SQL + Python + Visualisation = les 3 compétences qui te garantissent un emploi de Data Analyst.
- Les statistiques et le business sont ce qui te DIFFÉRENCIE des autres candidats.
- Tu n'as PAS besoin de maîtriser le machine learning pour commencer dans la Data.

H2 : 3. Le plan d'apprentissage en 6 mois (Data Analyst)

WARNING / ARNAQUE À ÉVITER : Tu n'as PAS besoin de payer 3 000 € pour une formation. Tu peux apprendre 100 % gratuitement avec les ressources ci-dessous.

H3 : Mois 1 : SQL

Semaine 1-2 : Bases de SQL (SELECT, WHERE, ORDER BY, LIMIT).

Semaine 3-4 : JOINs, GROUP BY, agrégations.

Semaine 5-6 : Sous-requêtes, window functions.

Projet : Analyser un dataset public (ex: ventes e-commerce) et répondre à 10 questions business.

Ressources : SQLBolt, HackerRank SQL, LeetCode SQL.

H3 : Mois 2 : Python pour la Data

Semaine 1-2 : Bases de Python (syntaxe, boucles, fonctions).

Semaine 3-4 : pandas (DataFrames, filtre, groupby, merge).

Semaine 5-6 : numpy, matplotlib, seaborn.

Projet : Nettoyer et analyser un dataset sales (même que Mois 1 mais avec Python).

Ressources : Kaggle Learn (Python, pandas), Real Python.

H3 : Mois 3 : Visualisation (Power BI ou Tableau)

Semaine 1-2 : Prise en main de l'outil, import de données.

Semaine 3-4 : Créer des visualisations (barres, lignes, heatmaps).

Semaine 5-6 : Créer un tableau de bord interactif complet.

Projet : Tableaux de bord de vente, marketing, ou finance.

Ressources : Microsoft Learn (Power BI), Tableau Public tutorials.

H3 : Mois 4 : Statistiques + Business

Semaine 1-2 : Statistiques descriptives (moyenne, médiane, écart-type).

Semaine 3-4 : Statistiques inférentielles (tests d'hypothèses, A/B testing).

Semaine 5-6 : KPIs business, métriques e-commerce, ROI.

Projet : Analyser un A/B test et faire des recommandations business.

Ressources : Khan Academy Statistiques, StatQuest YouTube.

H3 : Mois 5 : Projets concrets

Projet 1 : Analyse complète d'un dataset (SQL + Python + Power BI).

Projet 2 : Tableau de bord interactif sur un sujet de ton choix.

Projet 3 : Étude de cas business complète (problème → analyse → recommandations).

Mettre TOUS les projets sur GitHub avec README clairs.

H3 : Mois 6 : Portfolio + Recherche d'emploi

Optimiser ton profil LinkedIn (titre : "Data Analyst | SQL | Python | Power BI").

Créer un portfolio de 3-4 projets avec liens vers démos.

Postuler à 10-15 offres par semaine.

Préparer les entretiens techniques (SQL + cas business).

POINTS LES PLUS IMPORTANTS :

- La clé est de faire des PROJETS concrets, pas juste suivre des cours.
- Un portfolio de 3-4 projets vaut plus qu'un diplôme.
- Tu peux commencer à postuler DÈS le mois 5.

Ressources GRATUITES complètes :

- SQL : SQLBolt, HackerRank SQL
- Python : Kaggle Learn, Real Python
- Power BI : Microsoft Learn
- Tableau : Tableau Public
- Statistiques : Khan Academy, StatQuest
- Datasets gratuits : Kaggle Datasets, Google Dataset Search, data.gouv.fr

H2 : 4. Les projets à construire pour ton portfolio

WARNING / CONSEIL CRUCIAL : Un portfolio de PROJETS concrets est ce qui te fait embaucher. Pas les certifications. Pas les diplômes. LES PROJETS.

H3 : Projet 1 : Analyse de ventes e-commerce

Dataset : Ventes d'une boutique en ligne (10 000+ lignes).

Questions à répondre :
- Quel est le produit le plus vendu ?
- Quel est le CA mensuel ?
- Quel est le taux de conversion ?
- Quels sont les clients les plus fidèles ?

Outils : SQL (analyse), Python (nettoyage), Power BI (tableau de bord).

Livraison : Dashboard interactif + rapport de 5 pages avec recommandations.

H3 : Projet 2 : Analyse de données marketing

Dataset : Campagnes Facebook/Google Ads (dépenses, clics, conversions).

Questions à répondre :
- Quel canal a le meilleur ROI ?
- Quel est le coût par acquisition (CPA) ?
- Quelle audience convertit le mieux ?

Outils : Python (pandas), Tableau/Power BI.

Livraison : Dashboard marketing + recommandations d'allocation de budget.

H3 : Projet 3 : Analyse de données financières

Dataset : Données boursières ou transactions bancaires.

Questions à répondre :
- Quelle est la tendance du marché ?
- Quels sont les risques de fraude ?
- Quelle est la volatilité ?

Outils : Python (pandas, numpy, matplotlib).

Livraison : Analyse complète avec visualisations et insights.

H3 : Projet 4 : Étude de cas A/B testing

Dataset : Résultats d'un test A/B (version A vs version B d'un site).

Questions à répondre :
- Quelle version est meilleure ?
- Est-ce statistiquement significatif ?
- Quel est le ROI du changement ?

Outils : Python (scipy pour les tests statistiques).

Livraison : Rapport complet avec conclusion business.

H2 : FAQ – Questions Fréquentes sur Data & IA 2026

H3 : Quel est le meilleur métier Data pour un débutant ?

Data Analyst est le meilleur point de départ. C'est plus rapide à apprendre (3-6 mois), plus facile pour obtenir un premier emploi, et tu peux évoluer vers Data Scientist ou ML Engineer ensuite.

H3 : Faut-il un diplôme pour travailler dans la Data ?

Non. Un portfolio de 3-4 projets concrets vaut plus qu'un diplôme. 30 % des professionnels Data sont autodidactes.

H3 : Combien de temps faut-il pour devenir Data Analyst ?

6 mois minimum avec un apprentissage régulier (10-15 heures/semaine). Tu peux commencer à postuler dès le mois 5.

H3 : SQL ou Python : lequel apprendre en premier ?

SQL en premier (1-2 mois), puis Python (2-3 mois). SQL est la base absolue pour tous les métiers Data.

H3 : Data Analyst ou Data Scientist : quelle différence ?

Data Analyst : analyse des données existantes, crée des tableaux de bord, répond à des questions business. Plus facile à apprendre (3-6 mois).

Data Scientist : crée des modèles prédictifs, fait du machine learning. Plus difficile (12-18 mois) et demande des maths avancées.

H3 : Le secteur Data & IA va-t-il continuer à croître ?

Oui. Le marché a crû de 65 % en 2025 et continue d'exploder. L'IA a besoin de Data, donc la demande sera forte pendant au moins 5-10 ans.
